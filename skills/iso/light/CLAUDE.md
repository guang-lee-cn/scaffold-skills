# Light ISO —— 轻量级项目 Prompt 体系

> 适用于原型验证、小工具、业务系统等**非重型底层工程**的项目。
> 如果你需要完整的四层架构、五色数据流、ADR、盲点检查——请用根目录的 heavy 版。

## 规模自动适配

AI 根据用户的项目描述自动判断规模，无需手动配置：

| 规模 | 判断信号 | 流程深度 |
|------|---------|---------|
| **原型** | "验证""Demo""试试""跑通"、预计 < 1 周 | 只执行 discover.md 核心问题，直接进入 implement.md |
| **小工具** | "脚本""CLI""工具""转换"、单模块、1-4 周 | discover → implement，design.md 可选 |
| **业务系统** | "平台""服务""系统"、多模块、> 1 月 | discover → design → implement → deliver 完整流程 |

AI 在开始时间接确认："我判断这是 [规模]，流程深度为 [描述]，对吗？(Y/N)"

## 文件索引

| 文件 | 作用 | 何时加载 |
|------|------|---------|
| [discover.md](discover.md) | 问题定义 + 范围界定 | "开始""分析需求""想清楚" |
| [design.md](design.md) | 架构草图（可选） | "设计架构""拆模块"（仅业务系统必须） |

| [lang/cpp.md](lang/cpp.md) | C++ 速查 | 技术栈为 C++ 时自动加载 |
| [lang/go.md](lang/go.md) | Go 速查 | 技术栈为 Go 时自动加载 |
| [lang/python.md](lang/python.md) | Python 速查 | 技术栈为 Python 时自动加载 |

## 与 Heavy 版的区别

| | Heavy | Light |
|---|-------|-------|
| 适用 | 大中型 C++ 底层工程 | 原型 / 小工具 / 业务系统 / 全技术栈 |
| 流程 | 线性串行，强制门禁 | 非线性，可跳转，可跳过 |
| 图表 | 4 类强制图 + 五色规范 | 仅业务系统需要 1 张架构图 |
| 决策记录 | 至少 3 条 ADR（2+ 备选） | 仅记录关键取舍，不限格式 |
| 产出 | 全套 md 文档强制 | 原型：代码；工具：代码+README；系统：代码+设计文档 |
| 提问 | 逐条追问 + 盲点检查 | 一次抛出，用户自主选择回答深度 |
| 技术栈 | C++ 专用 | 语言无关，lang/ 提供速查卡 |

## 自由跳转

用户可以在任意时刻说：
- "跳过设计，直接写代码" → 进入 implement.md
- "先写代码，后面补文档" → 敏捷模式
- "回到需求，我改个范围" → 回跳 discover.md
- "只做集成测试" → 直接进入 deliver.md

AI 不强制回退上游，仅在用户请求时跳转。
