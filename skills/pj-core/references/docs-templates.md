## 2. 复盘文档（有价值问题 · 项目设计目录）

## 4. 通用规则

- **文件名带日期/版本号，按日期分卷不无限追加**
- 同日多版加 `-vN`；ISO 三活文档（insight/strategy/operations）固定名不加日期戳，修订记文件头版本节
- 正文去重：同一问题全文只写一次，日报/台账只引用编号
