# 评审维度检查清单（10 类 16 维 + 归属）

> 来源：评审复盘与SOP启示-2026-10-21（8 类 14 维实践）+ Google Code Review Developer Guide 8 维对标（补第 3 维「复杂度」缺口）。
> 用法：P1 审查准备时按清单逐维过一遍；**自动门禁维度由工具先行过滤，人工聚焦机器难查维度**（反过拟合纪律 0 同向）。

> **评审预扫（v0.3+，2026-10-22 组织根因落地）**：每轮评审前按**语言语义风险谱**主动预扫——**值语义 / 移动语义 / 异常安全 / 资源管理 / 生命周期 / 并发**——而非仅对照既往案例；发现新缺陷模式即补维，补维须对照风险谱系统排查（防"被动打补丁"，J-47 复盘组织根因）。

| # | 类 | 维度 | 审什么 | 归属 |
|---|---|---|---|---|
| 1 | 正确性 | 行为/竞态/边界 | 行为是否符合意图；短窗口竞态、配对键、边界值；**失败路径值语义：move 消费/参数求值副作用（emplace 带 move 实参）/后置条件（失败=无副作用）** | 人工聚焦 |
| 2 | 异常面 | 错误边界/泄漏 | 异常逃逸、双分配、nothrow 判定、失败类别编码 | 人工聚焦 |
| 3 | 并发 | 锁/时序/粒度 | RAII（CP.20）、锁序、CAS 双序、线程安全 | 人工聚焦 |
| 4 | **复杂度** | **可维护性（Google 第 3 维）** | **能否更简单？六个月后是否易懂？**；**函数体 ≤40 行即可（勿用过严行数标准）**；**无魔数：非平凡字面量具名常量（含类型尺寸/偏移/位宽/位数）、同源数字单点定义（单一权威）、移位/置位自注释**；**跨域同源声称须 grep 实证 + 域边界标注（引用即证据——4096 复盘模式 8：声称两容量同源/同值先跨模块查证，同值≠同源）** | **人工聚焦（新增）** |
| 5 | 测试 | 覆盖/质量/命名 | gtest 用例设计、假绿哨兵、GWT 命名、覆盖矩阵；**TDD RED→GREEN→REFACTOR 纪律（禁 code-before-tests，测试先行；方法论参照 obra/superpowers）** | 自动门禁（ctest/gcov）+ 人工 |
| 6 | 命名 | 头/类/API 命名 | PascalCase、惯例对齐、契约面命名 | 自动门禁（uncrustify/约定）+ 人工 |
| 7 | 注释 | 为什么/三分类 | **代码自解释优先（命名/具名常量/结构化表达），注释=兜底补充非替代**；A/B/C 分类、@file 精简、删除冗余 | 人工 |
| 8 | 风格 | 格式/一致性 | 排版、uncrustify | 自动门禁 |
| 9 | 静态/内存 | 静态分析/内存安全 | cppcheck/valgrind/ASan/TSan：未初始化、泄漏、越界、数据竞争 | 自动门禁 |
| 10 | QoS/容量 | depth/预算/背压 | depth 联动、抖动缓冲、总驻留预算、流控 | 人工 + 工具辅助 |
| 11 | 可观测 | 事件链/资源 | trace_id、statistics 桥接、L1/L2/L3 观测 | 人工 |
| 12 | 契约/ABI | 生命周期/导出面 | attach 悬垂、close 幂等、nm 导出、ABI 稳定 | 自动门禁（nm）+ 人工 |
| 13 | 构建/集成 | 编译/链接/门禁 | CMake 目标、ctest 集成、门禁链 | 自动门禁 |
| 14 | 文档 | 同步/交付 | 方案/内部设计同步、交付说明 | 人工 |
| 15 | 合规/安全 | 敏感信息/安全 | 密码/环境信息泄漏、注入面 | 自动门禁（合规 grep）+ 人工 |
| 16 | 复用/结构 | 重复实现/复用/边界一致性 | 重复实现 vs 复用（grep 实证 file:line）；同类结构是否下沉公共设施；模块边界与设计一致性 | 人工聚焦 + grep 实证 |

> **调试方法论参照（2026-10-22，superpowers 有效性评估落地）**：排查故障按 systematic-debugging 4-phase——**复现 → 根因 → 假设 → 修复**，禁止 patch-symptom（掩盖症状而非修复根因）；与 pj-core issues 九段式记录配套使用（记录台账 + 4-phase 方法）。

## 优先级原则（Google 排序）
设计/功能 > 复杂度 > 测试 > 命名/注释 > 风格/文档——评审文档按此优先级组织，不按发现顺序罗列。
