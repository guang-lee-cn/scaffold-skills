# 对弈复核协议（双向辩证）

## 疑问格式（编号 A~P 顺延）
| 疑问 | 对象（哪条发现/哪个结论）| 内容（含证据要求——原文/工具输出）|

## 回执格式
| 疑问 | 回执（确认/补充证据/撤回/拒绝+理由）| 新增证据 | 状态 |

## 校验 AI（meta-review）定位
- 时机：P2.5（两轮报告一出即校验）——**不参与对弈**（超脱）
- 产出：校验报告 = 误报清单（两轮都报错的证据）+ 盲区清单（两轮都漏的维度）+ 定级修正建议 + 流程检查（只读/证据归档/状态机）
- 校验对象是**报告**（不是代码）——防"共识性误判"（对弈双方基于同一错误前提互相印证）

## 纪律
1. **双向**：实现 AI 质疑审查 AI；审查 AI 间也互相质疑（不客套）
2. **实证优先**：疑问必须带证据要求（"引契约原文""grep 影响面"）——不空问
3. **撤回无惩罚**：实证推翻即撤回（编号保留——维持编号稳定）
4. **口径修正**：对方计数/影响面/行号错误——实证后纠正（如 4/9→5/8）
5. **≤2 轮**：第 2 轮未收敛 → 收敛清单 + G 拍板（不无限对弈）
6. **诚实时效**：发现自身误判立即撤回（不辩护）

## 常见疑问模板
- 定级依据？（推演 vs 实证——P0 需确定性复现路径）
- 证据原文？（引文件:行 原文）
- 影响面？（grep 实测——外部消费者）
- 与同族对比？（对照已有实证问题——I 编号）
- 引用版本？（文档版本与当前是否一致）
