# Notion Diagram（彩色分区 SVG 图风）

把架构类图统一画成「Notion 文档风」：每个语义分区一个柔和色相，靠 **浅底 + 同色系描边 + 同色系深色标题** 三件套表达层级，不用阴影、不用渐变、不高饱和铺底。

## 工作流（按序执行）

1. **ASCII 先定稿**：用 ASCII 图把布局、分区、连线、标号、文字排好，左右对齐，发用户确认。结构没确认前不渲染。
2. **通路标注**：给每个元素/每条箭头打两个标签——`通路归属`（RPC / pubsub / 共享 / 平台 / 域）、`关系性质`（数据流 / 回复 / 配置注入 / 汇聚 / 可缩减）。此步决定后续所有颜色与线型。
3. **复制骨架**：把 `assets/template.svg` 复制到目标文档的 `assets/`，按内容改 `viewBox` 尺寸。
4. **套 token**：所有颜色/字体/圆角/描边从 `references/style-tokens.md` 取，不临时臆造色值。
5. **渲染自检**：用 `scripts/render_check.sh`（Windows 用 Edge headless；Linux 用 rsvg/inkscape）转 PNG，`Read` 该 PNG 肉眼检查。
6. **回填**：Markdown 引用 SVG；按文档惯例保留 ASCII 折叠版（`<details>`）。

## 着色铁律

| 规则 | 说明 |
|---|---|
| 色相绑通路，不绑元素 | 一条数据通路的框、边、线、箭头、标号共用一个色相（RPC 蓝 / pubsub 青 / 平台紫 / 域黄绿）；同一条链路中途不许换色 |
| 一色一角色 | 一个语义角色 = 一个色相（浅底 + 同色系边 + 同色系深字）；同一角色全篇同色 |
| 两种着色模式二选一 | 按**角色**（Client/Server，拓扑/部署图）或按**职责**（RPC/pubsub/平台/域，内部结构图）；不混用，见 style-tokens.md |
| 深浅三档固定 | ① 分区浅底（tint≈10%）② 白底卡片 + 同色系细边 ③ 实色白字端点。全图不创第四档（无"加深档"） |
| 边随节点 | 从框引出的线、箭头 = 该框所属通路色；禁止"框蓝线黑/灰" |
| 共享节点中性化 | Context / Participant 等被多条通路共用的节点用中性白底灰边，不占色相；通路色以彩色线**穿过**节点，节点上可加双色小色条表示"多条通路经过" |
| 内层卡片白底 | 分区内部的卡片统一白底 + 同色系浅边，不再叠第二种底色 |
| 线型语义全图一致 | 实线 = 数据流/调用主路径（①②③ 全实线）；虚线 = 仅"配置注入（创建期）"与"可缩减同类"；分隔线用 1px 浅灰实线 |
| 域总线允许中性 | 汇入共享域/总线的线可用中性灰，但图例须注明"域总线"；域内再按通路分色 |
| 实色克制 | 仅逻辑端点（Requester / Replier 等）与标题栏用实色白字；DW/DR 等 DDS 实体一律白底彩边 |
| 色不超量 | 全篇色相 ≤4 + 中性；禁用渐变、阴影、高饱和 |
| 布局 | 同构分区对称、网格对齐、充足留白；用分隔线/分区底表达层级，不用框线硬围 |

## 连线工程（防"横线+箭头重叠"）

| 规则 | 说明 |
|---|---|
| 优先垂直直落 | 目标框中轴落在源框边界范围内时，直接用直线垂直连接（源框底边 → 目标框顶边）；禁止"先横折再下落"，横折只用于两框轴线不对齐 |
| 落线对准中轴 | 折线最后一段必须对准目标框的水平中轴（上下进入）或垂直中轴（左右进入） |
| 箭头冲刺段 ≥12px | 箭头 marker 前至少保留 12px 直线段（约 2 倍箭头高），箭头才能清晰伸展；不足则改垂直直落或加长冲刺段 |
| 拐点留白 ≥10px | 折线拐点与两侧框边界的距离均 ≥10px，防止横线/箭头/框边粘连 |
| 出口独立 | 多条线从同一容器出发时，各自从目标框正上方独立引出，不共用起点段（避免先重叠成一根再分叉的观感） |
| 渲染后复查 | 箭头尖必须清晰可辨：不贴框边线、不与横线段融成一体、方向与通路一致 |

## 资源

| 文件 | 用途 |
|---|---|
| `references/style-tokens.md` | 完整 design token：色板（中性/蓝/紫/青/黄绿/语义色）、字体、字号、字重、圆角、描边、间距、形状语义、两种着色模式与适用场景 |
| `assets/template.svg` | 可复用骨架：`defs` 箭头 + `<style>` 类名 + 示例分区/卡片/连线，新图直接复制改 |
| `scripts/render_check.sh` | 一键把 SVG 转 PNG 自检（自动探测 Edge/Chrome/rsvg） |

## 交付前自检

- [ ] **trace check**：渲染后只盯蓝追一次 RPC、只盯青追一次 pubsub，从业务框追到底；中间不得出现灰/异色/线型突变
- [ ] 同构分区对称、元素网格对齐，无错位/异常留白
- [ ] 所有文字无溢出、无截断，中文正常渲染（不是方块）
- [ ] 箭头方向正确（请求/回复、汇聚、注入、单向/多对多）
- [ ] 颜色按通路连续：框蓝线蓝、框青线青，无"框彩线灰"
- [ ] 深浅仅三档（浅底/白卡/实色端点），无自创深浅
- [ ] 虚线仅用于配置注入/可缩减；①②③ 全实线
- [ ] 连线检查：无"横线与箭头重叠"；箭头前直线段 ≥12px；落线对准目标框中轴；多线不共用起点段
- [ ] 标号（①②③）与连线一一对应；分隔线位置正确
- [ ] 已转 PNG 并 Read 核对；Markdown 引用路径正确
