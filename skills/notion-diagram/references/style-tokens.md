## 1. 着色模式

先判定图类型，再选模式，**全篇只用一种**：

| 模式 | 按什么分色 | 适用图 |
|---|---|---|
| A. 按角色 | Client/调用方 vs Server/服务方 | 部署拓扑、系统上下文、跨进程关系 |
| B. 按职责 | RPC vs pubsub vs 平台 vs 通信域 | 内部结构、分层、数据流、机制、状态机 |

**核心原则——色相绑通路，不绑元素**：一条数据通路上的框、边、线、箭头、标号共用一个色相；**共享节点（Context/Participant）中性化**，彩色线穿过节点，节点不占色相；紫色只留给"平台/外部配置（虚线注入）"。

**模式 A（角色）**：

| 角色 | 色相 |
|---|---|
| 调用方 / Client 进程 | 蓝 |
| 服务方 / Server 进程 | 紫 |
| 平台 / 外部配置（虚线） | 浅紫 |
| DDS Domain / 汇聚域 | 黄绿 |
| 数据汇聚线 | 绿 |
| 配置注入线 | 灰虚线 |

**模式 B（职责）**：

| 职责 | 色相 |
|---|---|
| rpc_api / RPC Core / Requester-Replier / RPC 通道 / ①② | 蓝（整条通路同色，穿过共享节点时线仍蓝） |
| pubsub_api / pubsub 端点 / pubsub 通道 / ③ | 青（整条通路同色） |
| 平台 / 外部配置（虚线注入） | 紫 |
| Facade Context / Participant（共享节点） | **中性**（白底灰边 + 双色小色条），不占色相 |
| 通信域 / 通道外框 | 黄绿 |
| 域总线（进程→域的中性汇入线） | 中性灰（图例注明） |

## 2. 层级三档

全图只有三档，不创第四档：

| 档位 | 画法 | 表达 |
|---|---|---|
| ① 分区 | tint≈10% 浅底 + 同色系描边 + 同色系深字标题 | 一个语义区域（进程/角色/域） |
| ② 卡片 | 白底 + 同色系细边（1.1–1.4） | 分区内的构件/实体；**RPC Core 也属此档**，不加深 |
| ③ 端点 | 实色 + 白字（圆角小块） | 仅逻辑端点（Requester/Replier/pubsub 端点/标题栏） |

> DW/DR 等 DDS 底层实体一律 **②白底彩边**，全图统一，不做实色。

## 3. 线型语义

| 线型 | 语义 | 用途 |
|---|---|---|
| 实线 | 数据流 / 调用主路径 | ①②③、进程内调用、RPC/pubsub 通道内连线 |
| 虚线（dash 6 3 / 5 4） | 配置注入 / 可缩减同类 | 平台配置下行、部署图中"…同类进程" |
| 1px 浅灰实线 | 分隔线（结构） | 层级划分、通道隔断，不做硬围 |
| 粗线（2.2–2.4） | 汇聚 / 强调 | fan-in 汇聚、域总线入口（绿或灰） |

> 线型全图同义。禁止用虚线表达"单向/多对多"——方向用箭头，多对多用文字与标号。

## 5. 字体

```
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Inter,
             "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", Arial, sans-serif;
```

- 代码符号（`RpcClient<S>`、`DataWriter`）同 sans，保持全篇统一；确需等宽用 `"SF Mono", Consolas, "Courier New", monospace`。
- 中文依赖 PingFang/微软雅黑/Noto CJK，渲染前确认不是方块。

## 7. 圆角描边间距

**圆角**：

| 元素 | 半径 |
|---|---|
| 页面 / 大分区 | 13–15 |
| 进程 / 中等容器 | 10–13 |
| 卡片 / 小框 | 6–9 |
| 端点 / 按钮 / 小药丸 | 5–6 |
| 输入条（全圆角） | 11 |

**描边**：

| 元素 | 宽度 |
|---|---|
| 大分区外框 | 1.8–2 |
| 容器 | 1.3–1.6 |
| 卡片 / 内边 | 1.1–1.2 |
| 分隔线 | 1 |
| 数据/汇聚线 | 2.2–2.4 |
| 普通连线 | 1.4–1.8 |

**间距**：分区内边距 14–16；卡片内边距 10–12；行距 6–8（行高 1.4–1.5）；分区间 20–32；元素对齐 8px 栅格。

**阴影：无。渐变：无。**

## 8. 形状语义

| 形状 | 表达 |
|---|---|
| 大圆角分区（pastel 底 + 同色系边） | 一个语义区域（进程 / 角色 / 域） |
| 白底卡片（同色系浅边） | 分区内的构件/实体（含 RPC Core、DW/DR） |
| 实色圆角块（白字） | 关键逻辑端点（Requester/Replier/pubsub 端点/标题栏） |
| 双色小色条 | 共享节点上标注"多条通路经过"（蓝+青） |
| 实线 + 箭头 | 数据流 / 调用方向 |
| 虚线 + 箭头 | 配置注入 / 可缩减同类 / 异步占位 |
| 1px 浅灰分隔线 | 层级或通道划分，不做硬围 |
| 圆圈/药丸标号（①②③） | 与连线路径一一对应 |
