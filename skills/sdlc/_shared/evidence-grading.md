# 证据分级（跨阶段共用）

> 作用：给每一条结论打 `(规范关系, 证据强度)` 二元组，使"规范要的 / 我们推的 / 我们自己加的"
> 在**产出时就分离**，而不是事后补标签。
> 版本：v0.1 草案（2026-10-17）

## 为什么是两轴，不是三类

单轴三分类（规范确认 / 自研推理 / 自研增强）把两个问题压成了一根轴：
- "规范怎么说" —— 规范关系
- "我凭什么这么说" —— 证据强度

压在一根轴上会出现**一条内容同时命中两类**的情况（例：某机制规范沉默、但由规范某条映射规则推导而来，
既可算"推理"也可算"增强"）⇒ **不正交**。

两轴的**可验证收益**：能容纳以下四种组合，单轴三类都装不下——

| 组合 | 含义 | 单轴三类的困境 |
|---|---|---|
| (A1, B4) | 规范要求，但我只是推导出来的、没读到原文 | 归"规范确认"则虚高；归"推理"则埋没规范义务 |
| (A4, B3) | 规范沉默，但我有实测数据支撑 | 归"增强"则掩盖实证；归"推理"则不精确 |
| (A5, B2) | **已知偏离**，且有代码事实 | **三分类根本没有这一格** |
| (A6, —) | **未定**，证据不足 | **三分类根本没有这一格** |

## 轴 A · 规范关系（这条内容对规范是什么关系）

封闭集，6 值，任一条**有且只有一格**。

| 码 | 名称 | 判定条件 | 硬要求 |
|---|---|---|---|
| **A1** | 规范要求 | 规范有 `shall` 明条 | 章节号 + 原文摘录（≥1 句） |
| **A2** | 规范定义 | 非 `shall`，但定义了名称/结构/映射规则；不照做就不能互操作 | 章节号 + 原文；说明"不照做会怎样" |
| **A3** | 规范允许 | `should` / `may` / 规范给了多个选项 | 记录选型理由 + 落选方案为什么落选 |
| **A4** | 规范未覆盖 | 规范对此沉默 | 论证"不与规范冲突" |
| **A5** | **已知偏离** | 规范要求 X，我们做（或只能做）Y | 偏离理由 + 影响面 + 能否收敛 + **谁批准** |
| **A6** | **未定** | 证据不足，无法判定 | 一等公民。必须写下"拿到什么证据才能定" |

### A5 与 A6 是不可省略的两格

- 缺 **A5 偏离**：偏离只能硬塞进"自研增强" ⇒ **把缺陷美化成特性**。这是最危险的失效模式。
- 缺 **A6 未定**：为了凑"完备"只能硬塞 ⇒ **完备性是假的**。

> 偏离到底是缺陷还是有意裁剪，取决于**有没有被批准**，不该由分类标签替我们决定。
> 所以 A5 必须带"谁批准"字段。

## 轴 B · 证据强度（我凭什么这么说）

按**可复现性**单调递减。

| 码 | 名称 | 复现成本 | 是否强制写反证条件 |
|---|---|---|---|
| **B1** | 规范原文 | 翻到该页即验 | 否 |
| **B2** | 代码事实 | 跑一条命令即验（`file:line` + 片段） | 否 |
| **B3** | 运行实证 | 跑一次测试（有复现步骤与结果） | 否 |
| **B4** | 链式推导 | 需审推导链 | **是** |
| **B5** | 经验判断 | 不可复现 | **是** |

**反证条件**：写出"什么观测结果会推翻这条"。写不出来 ⇒ 降级为 **A6 未定**，不许硬凑。

## 用法

1. 每条结论写成 `(A?, B?)` 二元组，如 `(A1,B1)`、`(A5,B2)`、`(A4,B5)`。
2. 只有 **B4 / B5** 必须附反证条件；B1–B3 天然可复现，免写。
3. 统计时按轴 A 汇总（合规覆盖率），按轴 B 汇总（结论可信度分布）。
   **两轴不要合并成一个分数** —— 合并就退化为单轴，正交性消失。

## 快速判定流程

```
规范里有没有 shall 明条？
├─ 有 → 我们照做了吗？
│       ├─ 是 → A1
│       └─ 否 → A5（偏离，必须记理由+批准人）
└─ 没有 → 规范是否定义了结构/命名/映射？
          ├─ 是 → A2
          └─ 否 → 规范是否给了选项（should/may）？
                  ├─ 是 → A3
                  └─ 否 → 规范完全沉默 → A4
                          └─ 但我拿不出"不与规范冲突"的论证 → A6
```

## 自检

- [ ] 每条都有且只有一个 A 值、一个 B 值
- [ ] 每个 B4/B5 都有反证条件
- [ ] A5 都填了"谁批准"
- [ ] A6 都填了"要拿什么证据才能定"
- [ ] 报表中 A、B 两轴**分开**统计，未合并成单一分数
