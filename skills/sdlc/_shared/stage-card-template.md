# 阶段卡统一模板

> 每个阶段卡（R1…P3）都按本模板写。**四要素缺一不可**：输入 / 输出 / DoD / 反例。

````markdown
# <段码><序号> · <阶段名>

> 版本：v?.?   归属：sdlc/<段>/

## 1. 输入（必填参数）

| 参数 | 来源 | 必填 | 缺失时怎么办 |
|---|---|---|---|
| <参数名> | <上一阶段产物 / 用户提供 / 代码> | 是/否 | **写"未定"，不许猜** |

## 2. 目标

一句话。不超过两行。

## 3. 步骤（有序，每步带判据）

| # | 动作 | 判据（做完的标志） |
|---|---|---|
| 1 | | |

## 4. 输出

| 产物 | 落点 | 模板 |
|---|---|---|
| | | |

产出表中**每一行**必须带证据分级 `(A?,B?)`，见 `_shared/evidence-grading.md`。

## 5. 退出条件 DoD（可检查，不是形容词）

- [ ] <可客观判定的条件>

## 6. 反例（禁止做的事）

> 这一栏来自既往教训，**不要留空**。

- ❌ <具体禁止项 + 为什么>

## 7. 自检命令

```bash
# 改仓库后必跑；期望输出写清楚
```
````

## 写卡纪律

1. **输入不许硬编码路径**。路径、时段、文件名一律参数化。
2. **DoD 必须可检查**。写"充分评估""尽量完整"的卡视为未完成。
3. **反例栏必须有内容**。空栏 ⇒ 这张卡没有承载过真实用例，标注为"未验证"。
4. **自检命令必须实际跑过一次**。纸面校验不算。
