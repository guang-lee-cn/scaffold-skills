# S4 · 工作包聚类

> 归属：`sdlc/S/`　版本：v0.1（2026-10-17）

## 1. 输入

| 参数 | 来源 | 必填 |
|---|---|---|
| shall 清单 | S3 | 是 |
| 现有架构组件 | S2 / 现状 | 否（有则用于归并） |

## 2. 目标

把散落的 shall 聚成**可交付、可排期**的工作包。

## 3. 步骤

| # | 动作 | 判据 |
|---|---|---|
| 1 | 按 **shall 的主语**分组 | 组间互斥 |
| 2 | 命名工作包（动词短语） | 名字符合其内 shall 的共性 |
| 3 | 检查正交：任一条 shall **有且只有一个**包 | 无重复归属 |
| 4 | 检查完备：所有 shall 已归包 | 未归包数 = 0 |
| 5 | 标优先级（合规点内 = P0，其余按业务） | 每行有优先级 |

## 4. 输出

`工作包表`：`包名 / 含 shall 数 / 章节出处 / 优先级 / (A?,B?)`

## 5. 退出条件 DoD

- [ ] 正交：无 shall 归属多包
- [ ] 完备：未归包 shall 数 = 0
- [ ] 兜底桶（"其它"）占比 < 20%
- [ ] 合规点（Conformance Points）相关包已标 P0

## 6. 反例

- ❌ 按规范目录聚类（同 S2 反例）
- ❌ 兜底桶过大 ⇒ 轴设计有问题，回去改轴，不要靠补丁条目填
- ❌ 把"已知偏离"塞进工作包当正常项 ⇒ 应标 A5 + 批准人

## 7. 自检命令

```bash
# 聚类后自检：shall 总数守恒
echo "清单条数=$(grep -c '\bshall\b' "$SPEC_PATH")"
echo "各包求和=$(cat 工作包表.md | awk -F'|' '/^\| [A-Z]/{s+=$3} END{print s}')"
```
