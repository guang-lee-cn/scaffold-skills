# S1 · 规范身份核验

> 归属：`sdlc/S/`　版本：v0.1（2026-10-17）　证据分级：见 `_shared/evidence-grading.md`

## 1. 输入（必填参数）

| 参数 | 来源 | 必填 | 缺失时 |
|---|---|---|---|
| `SPEC_PATH` 规范文件 | 用户提供 / 本地已有 | 是 | 停下索取，不许猜 |
| `SPEC_URL` 官网条目 | 用户提供 / 检索 | 是 | 标注「未核验身份」 |

## 2. 目标

在**读内容之前**先确认：这份规范是什么、哪一版、是否还有效。

## 3. 步骤

| # | 动作 | 判据 |
|---|---|---|
| 1 | 取文档号（如 `formal/2017-04-01`） | 能从官网独立复现 |
| 2 | 取版本号与发布日期 | 同上 |
| 3 | 取状态（formal / beta / 被取代） | 确认无替代版本 |
| 4 | 找 Machine Readable Files（PSM 绑定） | 有则记录文件名 |
| 5 | 查已知 issue / errata 列表 | 公开则记录，Members Only 则注明「无法核验」 |
| 6 | 记录文本抽取口径（PDF→txt？官方 txt？） | 明确声明失真风险 |

## 4. 输出

`规范身份卡`——上表 6 项，每行带 `(A?,B?)`。

## 5. 退出条件 DoD

- [ ] 文档号 / 版本 / 日期 / 状态 四项**全部**可从官网独立复现
- [ ] 已声明文本抽取口径
- [ ] 若为 PDF 抽取产物，已显式声明「表格/图示可能失真」

## 6. 反例

- ❌ **不核验身份就开始抽架构** —— 若版本错了，Phase 2 起整条链作废
- ❌ 把 PDF 抽取文本当权威原文
- ❌ 忽略 errata / issue 列表 ⇒ 把规范的已知错误当成义务
- ❌ "官网下只有一个版本" 不经核实就断言是最新

## 7. 自检命令

```bash
# 官网条目可访问性（本机 github.com 网页被封，需用户浏览器打开；API 可用）
curl -s "https://api.github.com/repos/<org>/<repo>/releases/latest" | head -40

# 本地规范计数口径（两个数要对得上，对不上说明按句切分逻辑有问题）
grep -c '\bshall\b' "$SPEC_PATH"
grep -o '[^.]*\bshall\b[^.]*\.' "$SPEC_PATH" | wc -l
```
