## 2. ⭐ 两条最关键的方法纪律

1. **S2 从 shall 反推，不从目录反推**
   > 目录是作者的组织方式，不是架构。照抄目录会得出"规范没有架构"的错误结论。

2. **S3 的两条坑**
   - `shall be able to` 是**能力陈述**，不是对实现的硬性义务
   - 必须区分**章节 normativity**：normative 附录算，示例 / informative 不算

## 3. 为什么 S 段是质量瓶颈

```
R ──→ S ──→ A ──→ I ──→ V ──→ D ──→ P
      ↑
   ①不准，②~⑥全歪
```

差异矩阵的每一行都以 S3 的 shall 为分母。**shall 没穷举 ⇒ "覆盖率"无意义 ⇒ A1 的 MVP 定界失去依据。**
