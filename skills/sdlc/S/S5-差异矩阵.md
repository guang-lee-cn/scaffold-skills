# S5 · 差异矩阵（规范 vs 现有方案）

> 归属：`sdlc/S/`　版本：v0.1（2026-10-17）

## 1. 输入

| 参数 | 来源 | 必填 |
|---|---|---|
| shall 清单 / 工作包 | S3 / S4 | 是 |
| 现有方案功能列表 | 架构文档 / 代码 | 是 |
| 合规口径（Q3：对标 or 裁剪） | **用户提供** | 是 |

## 2. 目标

给出「规范要什么 / 现在有什么 / 差多少 / 差得要不要紧」四列可判定结论。

## 3. 矩阵结构（四列齐全，缺一列即洞）

| 规范条款 | 方案/代码落点 | 差异 | 确认手段 |
|---|---|---|---|
| §x.y + 原文 | `file:line` 或「无」 | 一致 / 偏离 / 缺失 / 未定 | 命令 / 引用 / 测试 |

每行必须带 `(A?,B?)`。

## 4. 输出

`差异矩阵表` + 汇总统计（按轴 A 汇总合规覆盖率，按轴 B 汇总结论可信度分布）。

## 5. 退出条件 DoD

- [ ] **四列齐全**，无空列
- [ ] 每行有 `(A?,B?)`；B4/B5 带反证条件
- [ ] A5（偏离）项有理由 + 影响面 + **批准人**
- [ ] A6（未定）项有「要拿什么证据才能定」
- [ ] A、B 两轴**分开统计**，未合并成单一分数

## 6. 反例

- ❌ "确认手段"写「应该有」「代码里大概有」⇒ 不可复现，等于没确认
- ❌ 把偏离写成特性（缺 A5 格）
- ❌ 两轴合并成一个"合规分" ⇒ 正交性消失
- ❌ 只统计缺失，不标优先级 ⇒ 无法排期

## 7. 自检命令

```bash
# 矩阵自检：四列齐全 + 每行有分级
awk -F'|' 'NR>2 && NF>5 {if ($3=="" || $4=="" || $5=="" || $6=="") print "INCOMPLETE:", NR}' 差异矩阵.md
grep -c '(A[1-6],B[1-5])' 差异矩阵.md
```
