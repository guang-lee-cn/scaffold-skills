# A1 · MVP 定界【参数化】

> 归属：`sdlc/A/`　版本：v0.1（2026-10-17）
> 上游：**S5 差异矩阵**（有规范）／ **R4 冻结基线**　下游：**A2 架构方案**

## 1. 输入（必填参数，缺一不可）

| 参数 | 来源 | 缺失后果 |
|---|---|---|
| `周期` | 用户提供 | 无法判断能装下多少工作包 |
| `人力` | 用户提供 | 无法确定并行度 |
| `合规口径` | 用户提供 | 「规范缺失项」分不清是 P0 还是可接受裁剪 |
| `风险容忍` | 用户提供 | 未定项（A6）不知该排期补还是书面接受 |
| `shall 总数` | S3 产出 | 分母缺失 ⇒「覆盖率」无意义 |
| `工作包表` | S4 产出 | 无可排期对象 |

> ⚠️ **缺 `周期` / `人力` ⇒ A1 只能出候选集，出不了唯一 MVP。**

## 2. 目标

在约束下确定「一期做什么、不做什么」，且**每一项不做都有批准人**。

## 3. 步骤

| # | 动作 | 判据 |
|---|---|---|
| 1 | 列出全部工作包与 shall 数 | 与 S4 一致 |
| 2 | 按合规口径标注：**强制 / 可选 / 可裁剪** | 每行有标注 |
| 3 | 用周期 × 人力估算可装载量 | 有估算过程 |
| 4 | 切分：纳入 / 裁剪 / 延后 | 每包有归属 |
| 5 | **为每一个非"纳入"项指定批准人** | 无空缺 |
| 6 | 记录裁剪对下游（ADR / 验收）的影响 | 有记录 |

## 4. 输出

`MVP 定界表`：`包名 / shall 数 / 合规标注 / 归属 / 批准人 / 下游影响`

## 5. 退出条件 DoD

- [ ] 五参数齐备
- [ ] 每个非纳入项有批准人
- [ ] 裁剪项的下游影响已写明
- [ ] 纳入项总量与周期人力匹配（有估算）

## 6. 反例

- ❌ 无周期人力就定 MVP ⇒ 范围不可控
- ❌ 裁剪项无批准人 ⇒ 合规责任落空
- ❌ 只写"二期做"不写影响 ⇒ 下游踩空
