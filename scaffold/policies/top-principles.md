# 最高准则

> 层级：**最高准则 → SOP（`skills/iso` 的 I/S/O）→ skills（方法与判据）→ 项目局部规则（`pj-config.md`、DV）**。
> **下层只能收紧，不能放宽**；冲突时更具体者优先，并留一行偏离记录（`skills/router/SKILL.md` §4）。
> 写入与退役的条件见 `constraints-and-criteria.md` §1.1；偏离的登记字段与**免记情形**见 `templates/deviation-log.md.tpl`。
> 四条共同的作用只有一个：让判断**可被证伪**，而不是让流程看起来完备。
> 执行者假设：本体系按「派发可审计」建（router 保召回、回执 + 命中痕迹保审计），不按「通用模型须被强制」建（启动注入、绝对化措辞）。假设未变，注入 / 绝对化措辞类议题不再重开。

## 1. Reuse First（复用优先）

**能在现有实现上改，就别另起一套。**

**为什么**：AI 默认复制而非重构——Reuse First 是显式对抗机制，不写复用评估等于默许复制。

- 自检：**我改的这个能力，仓里已经有几份实现？为什么不是在最新那份上改？**
- 判据：指得出仓里已有的实现（`grep` 到 file:line）。指不出候选的「没法复用」不受理。
- 取材看**验证密度**：大量验证的开源优先（判据见 `skills/iso/references/oss-adoption.md` §2）；验证密度不足但维度突出的候选允许选，但记**验证债** + 补偿测试面。
- 必须留 DV：换实现（含只在外面包一层）、复用需要改上游语义（同时写**改动面**与**回移成本**）、同一能力出现第二份实现。
- 违反形态：交付时静默换实现；注释写复用、代码自建；把现有实现的缺陷当成「不能复用」的理由。
- 边界：**跨厂商可替换的项目里，适配层为隔离后端而存在的重复是隔离成本，不是技术债**。用「单一源 / 消除重复」去动它之前，先回答换掉后端时这份代码能不能整块丢弃（判据是换后端要改的面，不是代码行数）。

## 2. Global Over Local（全局优先）

**局部最优不等于整体最优；看的是放进系统边界之后的总代价。**

- 自检：**这个改动会动到谁？我列的是名字，还是 file:line？**
- 判据三件：**调用方清单**（`grep` 出的 file:line，不是「应该没别人用」）、**契约 diff**（公共符号 / 公共头 / 线上格式各自变了没有）、**受影响门禁**（哪些 gate 口径要跟着动）。
- 违反形态：为过门禁改阈值而不改实现；单点提速换来观测面丢失；新增字段只在一个调用路径上接线。

## 3. Falsifiability（可证伪）

**文档、注释、模型输出都是假设；实测 > 源码推导 > 文档。**

- 自检：**把这条改动改坏，哪个用例会红？我说得出名字吗？**
- 判据三条：① 写成一条会红的命令与预期失败输出；② 先在**改动前**量基线，同一判据在基线上给的是另一个值（恒真判据不算）；③ 新增或修改门禁时附一个已知会红的负例。
- 关键结论由另一方独立复现；反方规则见 `design-review-gate.md` 的对弈制。
- 违反形态：全绿当已验证；改完才补写判据；「找不到反例」没有尝试路径；把注释或旧文档当事实来源。
- 兜底：用例里为绕过已知坑加的一行（先扫一遍实体、先 sleep、重试一次）会让这个坑不再以红的形式出现。写兜底必须同时写「去掉它是红还是绿」，并留一条**不带兜底**的用例。

## 4. Single Source of Truth（口径唯一）

**一处定义、他处引用；复制即分叉。**

- 自检：**这条规则的唯一落点是哪？我改的是落点，还是它的副本？**
- 判据：期望清单与生成物**双向**比对（单向包含不够）；文档里的数字能追到生产它的命令。
- 违反形态：规范与代码各写一份；同一常量两处定义；文档写「九值」而枚举已经十值。

## 5. Assertions and Attribution（断言与归因）

**注释、文档、评审结论、文档里的数字都是断言；每一条都要指得回实际写点或产生它的命令。**

- 自检：**这条说法我是在哪儿核实的？指得出 file:line 或命令输出吗？指不出就不写。**
- 分层归因：症状（「乱」「慢」「难看」）不等于病灶。归因要落到**层**——方案（系统怎么切）/ 标准（代码长什么样）/ 执行（这批具体怎么写的）——并指出改哪一层才治本。只改执行层而病灶在标准层，同一个问题下一批必然复发。
- 回源：写状态语义、契约边界、默认值之前回读实际写点；评审结论只能当线索，不能当依据。归因要指向**失败状态的来源**，不指向耗时或任何可观测指标——「等一下就好」与「永远好不了」在耗时上是同一条曲线。
- 引用面：改正一条被多处引用的事实（目录是否入库、门禁基准、默认值）前，先 `grep` 旧表述，逐处改或逐处加「更正说明 + 依据」；只改主文档、留引用处说反话，等于把同一个错误分散存放。
- 数字：凡是会被当成判据基线或复核对像的数字（用例数、skip 数、门禁数、文件数），一律附产生它的命令，不许凭记忆写。
- 频率：写「必现 / 间歇」之前先写验证方法与最小样本量；两个样本同结论不构成排除间歇。
- 时序：一切上界 / 超时用**单调钟**计时。墙钟会被 NTP 或宿主校时回拨，以它建 deadline 的等待会把调用方给的上界延长同一量级，且不给任何错误码。
- 违反形态：照抄评审前提写出与代码相反的注释；把「慢」归因成「坏」；改了一处口径不扫引用面；凭记忆写判据数字。
