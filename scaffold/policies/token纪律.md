# Token 节省纪律（不降交付标准）

- 上下文管理（最大头）：单轮任务 ≤ 上下文 60%；subagent 上下文隔离（只带所需）
- 角色成本：派一个 subagent ＝ 重述上下文（规范 / 裁决 / 卡面）+ 它独立读懂代码 + 回收摘要并由派发者复核。三笔都是固定开销，买到的只有「独立性」与「并行」；不满足 `sop/协作流程-通用版.md` §1 两条判据就不派
- 技能成本：按需加载，一次文件读取；把可机械判定的口径（lint / 门禁 / 提交禁词 / 模板）放进 skill 或脚本，永远比每轮让某个角色重新理解一遍便宜
- 输出瘦身：报告人可读优先（禁黑词）；门禁 JSON/证据链/精确栈另行存档（双文档策略）
- 流程侧：先探查再行动；不重复读已定稿文档；沉淀 skills 减少重复长文
- 工具侧：批处理/聚合脚本替代逐条；只读优先
- 软红线：省 token 不得省验证（门禁/证据链完整）
