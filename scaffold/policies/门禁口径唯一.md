# 门禁口径唯一（防假绿）

- 一门禁一命令：所有角色只用 quality/run_gate.sh 一个口径；禁止"自己跑一遍不同命令"声称通过
- 防假绿三查：命令存在性（缺失 = FAIL 不空跑）/ exit code 真实捕获 / 解析正则命中才记 PASS
- 先 RUN 再 claim：声称"测试通过/构建成功"必须有本次运行输出；禁 should/probably/seems
- 假绿对照：测试通过=本次 0 失败；构建成功=exit 0；修复完成=原症状复测；已推送=git log 核实
- 抑制有效性：以门禁口径实测归 0 为准，不以注释存在为准（cppcheck suppress 按行就近 vs NOLINT 按行尾，语义不同）
